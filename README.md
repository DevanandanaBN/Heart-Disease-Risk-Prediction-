# Heart Disease Risk Prediction Using Machine Learning

## About the Project

This project is a Machine Learning-based Heart Disease Risk Prediction system.
It uses patient health-related information to predict whether a person is
likely to have heart disease.

The project uses the **Gaussian Naive Bayes** classification algorithm to
train the model and make predictions.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The project uses a dataset named `heart.csv`.

The dataset contains various health-related attributes such as:

- Age
- Sex
- Chest Pain Type (cp)
- Resting Blood Pressure (trestbps)
- Cholesterol (chol)
- Fasting Blood Sugar (fbs)
- Resting ECG (restecg)
- Maximum Heart Rate (thalach)
- Exercise Induced Angina (exang)
- Oldpeak
- Slope
- Number of Major Vessels (ca)
- Thalassemia (thal)

The `target` column is used as the output:

- `0` = No Heart Disease
- `1` = Heart Disease

## Project Workflow

The project follows these steps:

1. Import the required libraries
2. Load the heart disease dataset

14. Create a Gaussian Naive Bayes classifier
15. Train the Machine Learning model

18. Generate classification report
19. Generate confusion matrix

## Machine Learning Algorithm

### Gaussian Naive Bayes

Gaussian Naive Bayes is a classification algorithm based on Bayes'
Theorem. It assumes that the features follow a Gaussian (normal)
distribution within each class.

In this project, Gaussian Naive Bayes is used to classify patients into:

- No Heart Disease
- Heart Disease
